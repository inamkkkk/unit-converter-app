# Unit Converter App

A simple unit converter app built with Flutter.

## Features

*   Converts between different units (e.g., temperature, length, weight).
*   User-friendly interface with dropdown menus.
*   State management using Provider.
*   Persists last used units using shared preferences.

## Getting Started

1.  Clone the repository.
2.  Run `flutter pub get`.
3.  Run `flutter run`.
